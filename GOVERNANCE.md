# Governance

## Project model

Moon is maintained under a maintainer-led model.

## Roles

1. Maintainers
   - Merge/reject pull requests.
   - Cut releases.
   - Set roadmap direction.
2. Contributors
   - Propose and implement changes via pull requests.
   - Follow `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md`.

## Decision process

1. Small fixes: maintainer review + merge.
2. Behavior changes: must include rationale, tests, and docs updates.
3. Breaking changes: require explicit migration notes in `CHANGELOG.md`.

## Release authority

Maintainers are responsible for versioning, tagging, and release publication.

## Security authority

Security handling follows `SECURITY.md`. Maintainers coordinate disclosure and
patch release timing.
